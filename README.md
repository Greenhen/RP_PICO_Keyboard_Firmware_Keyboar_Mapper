# Raspberry Pi Pico billentyűzet firmware és mapper

Ez a repó a laptopbillentyűzet önálló Raspberry Pi Pico firmware-ének
és a billentyűzetmátrix feltérképező eszközének fejlesztési történetét
tartalmazza.

## Fejlesztési állapot

Az önálló billentyűzet-firmware fejlesztése ebben a repóban nem
folytatódik tovább.

A billentyűzet és a PS/2 touchpad közös USB HID firmware-ének aktuális
fejlesztése itt található:

[Pico-Laptop-HID-Firmware](https://github.com/Greenhen/Pico-Laptop-HID-Firmware)

Ez a repó referenciaként és a billentyűzet fejlesztési előzményeinek
megőrzésére továbbra is elérhető marad.
